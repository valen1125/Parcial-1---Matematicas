# 📐 Taller de Cálculo Integral

Plataforma web modular para el aprendizaje interactivo de **Cálculo Integral** y **Métodos Numéricos**. Diseñada con interfaz *Glassmorphism* y renderizado dinámico de fórmulas en LaTeX.

---

## 📚 Módulos del Taller

### 🟢 Fase 1: Fundamentos y Métodos Numéricos (Disponibles)
- **Módulo 01:** Sumas de Riemann (Aproximación por rectángulos)
- **Módulo 02:** Regla del Trapecio (Integración numérica)
- **Módulo 03:** Regla del Punto Medio
- **Módulo 04:** Regla de Simpson (Aproximación parabólica)
- **Módulo 05:** Integral Definida y Área Bajo la Curva
- **Módulo 06:** Integración Directa e Inmediata

### 🟡 Fase 2: Técnicas de Integración (Próximamente)
- **Módulo 07:** Integración por Sustitución
- **Módulo 08:** Integración por Partes
- **Módulo 09:** Sustitución Trigonométrica
- **Módulo 10:** Fracciones Parciales

### 🟡 Fase 3: Aplicaciones e Integrales Impropias (Próximamente)
- **Módulo 11:** Integrales Impropias
- **Módulo 12:** Volúmenes de Sólidos de Revolución
- **Módulo 13:** Longitud de Arco
- **Módulo 14:** Centroides y Trabajo

---

## 🛠️ Tecnologías
- HTML5 / CSS3 (Diseño Neón Glassmorphism)
- JavaScript & KaTeX (Renderizado matemático)
