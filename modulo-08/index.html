Módulo 08: Exponenciales y Logarítmicas

Antiderivadas con base $e$, bases generales $a^u$ y formas logarítmicas naturales.

1. Fórmulas Fundamentales

$$\int e^u\,du = e^u + C \qquad \int a^u\,du = \frac{a^u}{\ln a} + C \qquad \int \frac{du}{u} = \ln|u| + C$$

2. Ejemplo Resuelto

Calcular: $\int \frac{3x^2}{x^3 + 5}\,dx$

Paso 1 — Identificar el denominador: Sea $u = x^3 + 5$, su derivada es $du = 3x^2\,dx$.
Paso 2 — Aplicar regla logarítmica:
$$\int \frac{du}{u} = \ln|u| + C$$
Respuesta: $\ln|x^3 + 5| + C$
